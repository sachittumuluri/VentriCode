# VentriCode Frontend

React.js frontend for VentriCode - Ventricular Tachycardia Detection System

## Quick Start

```bash
npm install
npm start
```

## Features
- ECG file upload interface
- Real-time analysis visualization
- Patient management dashboard
- Medical report generation

## Team Structure
- Frontend developers work on this branch
- Backend developers work on `main` branch
- Integration via REST API at `http://localhost:8000`
